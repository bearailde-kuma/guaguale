# Project instructions

- Target Godot 4.5.1 Standard; use GDScript and Compatibility rendering.
- Keep Chinese player-facing copy and an offline-first single-player experience.
- State changes belong in `scripts/core/game_state.gd`; UI must not mutate economy state.
- Reuse the existing JSON catalogs for balance changes. Preserve stable content IDs and save compatibility.
- Outcome generation must use the injected gameplay RNG, never UI/audio randomness.
- Keep previewed/purchased outcomes stable across saves; never pay the same ticket twice.
- After core changes run `tests/run_tests.gd`. After balance changes also run `tests/simulate.gd` and update the numerical summary.
- After presentation changes inspect screenshots from a real Godot render. Avoid claiming Windows testing unless a Windows runtime actually ran.
- Keep `.godot` and generated `builds/` out of git. Do not overwrite unrelated repository contents.
- Font and engine licenses must accompany redistributable builds. Original art and audio are generated by this project.
- Current save schema is 3. Preserve v0.1 `legacy` and v0.2 paid boards, unlocks, and rewards; never append a skull during migration.
- The authoritative base prize comes from `TicketRules.evaluate()`, not `payout` or arbitrary cell sums. Test every new rule after JSON roundtrip.
- Automation must use normal transactions, preserve the selected-ticket cash reserve, charge spirit only once per ticket, and pause in menus.
- Spirit has no passive/offline recovery. Breakthroughs/assets expand capacity but do not heal.
- Skull risk is once per ticket, independent of scratch area count; persist its index before reveal. Alchemy never rerolls it.
- Fatal revelation ends the run before payout. Meta rewards are granted exactly once and persisted before signals.
- Talents may be purchased only between runs. Normal reincarnation preserves meta state; full reset is a separate explicit UI action.
- New mathematical rules live in MysticRules; validate their save shape and add independent known-result examples, not only generated roundtrips.
